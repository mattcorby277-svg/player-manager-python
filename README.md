# player-manager-python
A beginner‑friendly Python project that demonstrates all core programming fundamentals. This program allows you to add, remove, view, and analyse player data using a menu‑driven system.

----------

Features
----
Add players with unique names

Remove existing players

View all players and their stats

Show highest, lowest, and average score

Input validation and error handling

Uses sets, dictionaries, tuples, functions, loops, and built‑in functions

------------
Skills Demonstrated
-------
Variables, input, strings

Conditionals and loops

Functions

Sets, dictionaries, tuples

Error handling (try/except)

Type casting (int())

Built‑in functions (max, min, sum, len)

random module
